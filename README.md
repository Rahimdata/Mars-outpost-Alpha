# Mars: Outpost Alpha

**Mars: Outpost Alpha** is a browser-based Mars survival and colony-management game. Guide a crew through a ten-Sol campaign by exploring the surface, maintaining outpost systems, managing supplies, and making decisions that shape the mission outcome.

The game introduces young players to mission planning and resource trade-offs through rover exploration, crew interactions, colony management, and a science archive. Campaign resource values and outcomes are simplified game simulations—not live NASA telemetry or operational mission forecasts. NASA learning resources are credited in the in-game science archive.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Controls

In the 3D world, use **WASD** to move, **Shift** to run, **Space** to jump, and **E** to interact. Use the mouse to look around. In-game prompts and the controls panel explain other actions.

## Built with

React, TypeScript, Vite, Three.js, and React Three Fiber.
